# CodeAlpha Power BI Internship Projects

This repository contains 3 Power BI dashboards built as part of my Data Analytics internship with CodeAlpha.

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (data cleaning and transformation)
- DAX (measures and calculated columns)

## 📊 Task 1: Financial Health Dashboard
A 3-page dashboard analyzing sales, profit, and cost trends using Power BI's built-in Financials dataset.
- Executive Summary with KPI cards and sales forecast
- Profitability analysis with a waterfall chart
- Budgeting page with a What-If parameter for scenario planning

📁 [`Task1_Financial_Dashboard/CodeAlpha_FinancialDashboard.pbix`](./Task1_Financial_Dashboard/CodeAlpha_FinancialDashboard.pbix)

## 👥 Task 2: HR Analytics Dashboard
A 3-page dashboard analyzing employee attrition using the IBM HR Analytics dataset.
- Overview with attrition rate, headcount, and department breakdown
- Attrition analysis by age, income, and department
- Workforce insights with satisfaction and tenure trends

📁 [`Task2_HR_Analytics/CodeAlpha_HRAnalytics.pbix`](./Task2_HR_Analytics/CodeAlpha_HRAnalytics.pbix)

## 🏠 Task 3: Real Estate Market Trends
A 3-page dashboard analyzing King County house sales data.
- Market overview with price trends and property counts
- Geographic heatmap of prices by zip code
- Investment insights including price-per-sqft analysis

📁 [`Task3_RealEstate/CodeAlpha_RealEstate.pbix`](./Task3_RealEstate/CodeAlpha_RealEstate.pbix)

## 📌 About
These projects were completed as part of the CodeAlpha Data Analytics Internship, focusing on data cleaning, DAX measure creation, and interactive dashboard design in Power BI.
